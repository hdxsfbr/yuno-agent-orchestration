OpenClaw 2026.10.3 from a pinned image plus a static Docker CLI (docker/openclaw.Dockerfile). It executes every agent turn, owns sessions and transcripts, runs tools in sibling sandbox containers through the mounted Docker socket, serves the Telegram channel natively, and talks to the platform over its WebSocket RPC protocol (v4). Memory and heap limits (4 GB, 3 GB) and a restart policy are set in compose.
