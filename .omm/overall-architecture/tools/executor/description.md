executor.go runs a tool with its timeout and retry budget; for side effects it inserts the idempotency key in a transaction with SELECT FOR UPDATE, calls the service, stores the result, deletes the key on failure and replays a stored result on a repeat (output.replayed true). ExecuteApproved is the engine's fallback for a grant that arrives after the MCP wait ended. canonical.go defines the key: sha256 of run id, node visit id, tool name and canonical JSON input without the run token.
