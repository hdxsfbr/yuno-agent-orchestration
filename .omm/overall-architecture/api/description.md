internal/httpapi is the Go process behind every compose role except the deploy target: the HTTP API with its OpenAPI contract (api/openapi.yaml), SSE streams, the MCP server that serves platform tools to the gateway behind a bearer gate, the model proxy that injects the provider key, the startup sequence (dial the gateway with indefinite backoff, start the engine, keeper, scheduler, sweeper, template loader) and the watchdog that ends the process when its network namespace dies.
