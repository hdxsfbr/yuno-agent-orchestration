mcp.go serves the tool registry over MCP streamable HTTP (stateless) and gates every call: resolve the run token to its run context, refuse tools outside the agent's allowlist or blocked by interaction rules or guardrails, validate the input, match guardrail input patterns, compute the idempotency key for side effects, record the authoritative tool_calls row, then execute directly (auto) or request an approval and block up to MCP_TOOL_WAIT_SECONDS; results are rejected, pending_approval or the tool's output, redacted and capped.
