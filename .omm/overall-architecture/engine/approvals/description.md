approvals.go implements the contract: RequestApproval records a tool approval, registers it with the gateway as a two-phase plugin approval and pauses the run; WaitApproval blocks the MCP handler until a decision; DecideApproval applies approve, approve_always or reject by kind (exec resolves on the gateway, tool resolves the plugin approval and resumes, node re-queues the run), delivers to a waiter or executes a late grant through the SideEffectExecutor into runs.state.pending_effects; an expiry sweeper fails runs whose approvals timed out; the gateway's own timeout events are ignored.
