internal/engine runs workflows: Trigger validates and queues a run with a snapshot of its definition and layered limits; workers claim queued runs and walk the graph; an agent node visit is one OpenClaw turn on a node-scoped session with the run token and finish protocol; approvals of three kinds pause or block runs; limits are checked on every event and on a tick; conversations from Telegram are mirrored into Postgres. internal/sched fires scheduled runs with an occurrence key.
