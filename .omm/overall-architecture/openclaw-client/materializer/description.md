materialize.go computes the desired gateway state for an agent (config entry with model, thinking, tool allow and deny lists, exec policy, workspace files SOUL.md, AGENTS.md, MEMORY.md, skills) and its hash; when the hash differs it creates the agent if needed, patches agents.entries.<id> while re-asserting explicit ownership, sets the exec approvals file and writes the files atomically through an os.Root. Guardrails feed the denied tools and the exec policy.
