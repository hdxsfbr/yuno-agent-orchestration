An agent is configured entirely from the user interface, without touching code. The Agents page lists the six demo agents with the channel each one is bound to and its live state. Opening the Coder shows every dimension the brief names: its role and system prompt, the model, the tools it may use and, for each tool, whether it runs on its own, needs a human approval, or is blocked. Below that are the operating limits, the guardrails for cost, rate and blocked inputs, the memory policy with retention, the skills it can load, its exec policy, and the Telegram line. Saving pushes all of this into OpenClaw, and the runtime card shows what the gateway actually holds, including the markdown files that define the agent there.
