The evaluation suite runs offline against the same stack with a deterministic scripted model, so no cloud is needed to evaluate the platform. Twenty-four versioned cases, seventeen public and seven private, each judged by seven deterministic evaluators: termination, trace integrity, expectations, the approval gate, idempotency, schemas and allowlists, plus a rubric graded heuristically offline or by a real model when asked. The report in the repository is reproduced by make eval; this one is the baseline with every case passing.
