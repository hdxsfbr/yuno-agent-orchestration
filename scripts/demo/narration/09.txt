Runs can also start on a schedule. From the Schedules page I create a once-schedule for the research pipeline, two minutes from now, with its input. The scheduler picks it up on its next tick; the row shows the last run and, for repeating schedules, the next one, in any time zone. The run appears in the Runs list with the trigger set to schedule, and the Researcher starts working. The Status page shows the commit the stack was built from, the gateway connection, the scheduler's tick and next due time, and the queues.
