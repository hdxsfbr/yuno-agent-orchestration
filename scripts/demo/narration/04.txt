Coder writes the code and runs the tests in its sandbox; when it finishes, its typed output becomes state and a message to Reviewer. Reviewer runs the tests itself and approves. The run now waits at the human gate; I approve it from the inbox. Deployer calls the deploy tool, which is side-effecting, so the call itself blocks for approval; approved, it runs exactly once under its idempotency key and the release appears on the local deploy target. The trace shows every call, token and cent.
